# Reporting a security vulnerability

Use [GitHub’s private vulnerability reporting form](https://github.com/clarkdickens/canary-support/security/advisories/new) to reach the maintainer privately. Include your Canary version, operating system, the behavior you observed and its impact. When an example is helpful, use fictional data.

For general questions and bugs, use [Canary support issues](https://github.com/clarkdickens/canary-support/issues).
